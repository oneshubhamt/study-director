# Working on Study Director

This is a private, source-available project. Contributions require the copyright holders' authorisation; the existing [licence](LICENSE) applies.

Use Node.js 22 and Python 3. The [README](README.md) explains building and running the app.

- Create a branch for each coherent change and open a pull request to `main`. Describe the resulting behaviour, the objectives and the checks actually run; the pull request template has the sections.
- Keep runtime changes separate from unrelated formatting or repository maintenance.
- Generated `dist`, installed dependencies, personal backups and QA output do not belong in commits.

How to work, choose tests, build and release: [docs/workflow.md](docs/workflow.md). Rules for AI agents: [AGENTS.md](AGENTS.md). Map of the documentation: [docs/README.md](docs/README.md).
