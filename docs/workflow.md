# Implementation workflow

On `TS-Conversion`, [AGENTS](../AGENTS.md), [binding decisions](typescript/DECISIONS.md), and [the execution control record](../TS-CONVERSION-EXECUTION.md) govern work. The control record is the persistent scratchpad; keep a second temporary pad outside the repo. Inspect → analyze → implement → reconcile source/objectives → targeted QA → record evidence and commit/push only this branch.

Use [verification](VERIFICATION.md) for check selection and [the test guide](../tests/README.md) for runner rules. Full certification remains Phase 7. The imported [production test programme](history/PRODUCTION-TEST-PROGRAMME.md) and [production history](history/PRODUCTION-MAIN-HISTORY.md) are provenance, not an additional active schedule or permission to deploy. [Backlog](backlog.md) holds product ideas outside the current pass.
